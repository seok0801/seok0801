# 마카오 가족여행 2026.12.27–31 · 3D 투어맵

**사이트 주소: <https://seok0801.github.io/seok0801/>**

휴대폰이든 PC든 위 주소를 누르면 열립니다. 처음에는 아래 [웹 주소 켜기](#처음-한-번-웹-주소-켜기)를 한 번 해 두어야 주소가 열립니다.

## 이 사이트로 할 수 있는 것

- **날짜 탭**(전체, 27 ~ 31일)을 누르면 그날 장소로 지도가 이동하고, 그날 동선만 진하게 보입니다.
- **일정**은 시간·제목·장소만 한두 줄로 보입니다. **누르면** 지도가 그 장소로 날아가고, 메모·꿀팁·예약 버튼이 펼쳐집니다. 다시 누르면 접힙니다.
- **▶ 투어**를 누르면 그날 장소를 순서대로 날아가며 3초씩 머뭅니다. 머무는 동안 카메라가 장소 둘레를 천천히 돌고, 그 자리에 빛기둥이 섭니다. ⏮ ⏭ 로 앞뒤 이동, 다시 누르면 일시정지.
- 지도에서 **마커나 이름표를 누르면** 그 장소의 설명·꿀팁·예약 버튼이 팝업으로 열립니다.
- **📋 예약**에 예약이 필요한 곳만 모여 있습니다(예약 체크리스트). 버튼을 누르면 새 탭으로 예약 페이지가 열립니다.
- **💰 비용**에 1가족(어른 2, 아이 1) 기준 날짜별·전체 예상 비용이 나옵니다(비용 요약).
- 일정의 주황색 표시는 확인이 필요한 곳입니다: **영업시간**, **휴무**, **아이 리듬**, **확인 필요**. 펼치면 이유가 나옵니다.
- 휴대폰에서는 목록 위의 **손잡이(짧은 막대)** 를 누르면 목록이 커지고 지도가 작아집니다. 다시 누르면 돌아옵니다.
- 인터넷이 약해 지도가 안 떠도 일정 목록과 예약 버튼은 그대로 보입니다.

## 여는 법

1. **주소로 열기**: 맨 위 사이트 주소를 누릅니다. 가족에게는 이 주소를 메신저로 보내면 됩니다.
2. **파일로 열기**: 이 페이지 위쪽의 초록색 `Code` 버튼 → `Download ZIP` → 압축을 풀고 `index.html` 을 더블클릭합니다. (지도는 인터넷이 있어야 보입니다.)

## 처음 한 번: 웹 주소 켜기

1. 이 저장소 화면 위쪽의 `Settings` 를 누릅니다.
2. 왼쪽 메뉴에서 `Pages` 를 누릅니다.
3. `Build and deployment` 아래 `Source` 를 **GitHub Actions** 로 바꿉니다. (저장 버튼은 따로 없습니다.)
4. 그 뒤 `main` 에 변경이 반영(Merge)되면 1~3분 안에 주소가 열립니다. 위쪽 `Actions` 탭에 초록 체크가 보이면 배포가 끝난 것입니다.

빨간 X 가 보이면: `Actions` 탭 → 왼쪽의 `GitHub Pages 배포` → 오른쪽 `Run workflow` → 초록색 `Run workflow` 를 눌러 다시 실행합니다. (Pages 를 켜기 전에 반영하면 첫 실행이 실패합니다. 켠 뒤 다시 실행하면 됩니다.)

## 일정 고치는 법

### 방법 1 (추천): Claude에게 우리말로 부탁하기

[claude.ai/code](https://claude.ai/code) 에서 이 저장소로 새 세션을 열고 우리말로 요청합니다. 예: "12/30 워터파크를 오전으로 옮겨줘". 작업이 끝나면 `Create PR` → `Merge pull request` → `Confirm merge` 를 누르면 1~3분 뒤 사이트가 바뀝니다.

### 방법 2: `data.js` 를 직접 고치기

일정·장소·예약 링크는 모두 `data.js` 한 파일에 있습니다.

1. 이 저장소 화면에서 `data.js` 를 누릅니다.
2. 오른쪽 위 연필 모양(Edit this file)을 누릅니다.
3. 아래 예시처럼 고칩니다.
4. 오른쪽 위 초록색 `Commit changes...` → 다시 `Commit changes` 를 누릅니다. 1~3분 뒤 사이트가 바뀝니다.

지킬 것 3가지: 글자는 작은따옴표 `' '` 안에 쓰기, 시간은 `'09:30'` 처럼 24시간제로 쓰기, 줄 끝의 쉼표 `,` 지우지 않기.

**예시 1 — 시간과 장소 바꾸기.** 12/30 저녁을 18:00 푸드 리퍼블릭에서 17:30 딘타이펑으로 바꾸려면, `data.js` 에서 이 줄을 찾아

```js
date: '2026-12-30', time: '18:00', kind: 'meal', meal: 'dinner', title: '저녁: 푸드 리퍼블릭 (스튜디오 시티)', places: ['foodrepublic'],
```

이렇게 고칩니다. (`time` 이 시간, `title` 이 카드에 보이는 글, `places` 가 지도에 찍히는 장소의 이름표입니다. 이름표는 파일 위쪽 '장소 목록'에 있습니다.)

```js
date: '2026-12-30', time: '17:30', kind: 'meal', meal: 'dinner', title: '저녁: 딘타이펑 (스튜디오 시티)', places: ['dtf'],
```

**예시 2 — 예약 링크 바꾸기.** FEAST 뷔페 예약 주소를 바꾸려면, 파일 가운데 '예약 링크' 부분에서 이 줄을 찾아

```js
url: 'https://www.feastmacao.com/',
```

작은따옴표 안의 주소만 새 주소로 바꿉니다. 주소가 열리는 것을 직접 확인했다면 그 위 줄의 `linkVerified: false` 를 `linkVerified: true` 로 바꿉니다.
